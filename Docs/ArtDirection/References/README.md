# Días Prestados — referencias visuales (concept art original)

Este directorio es material de **dirección artística** para el prototipo en Unity 6.6. **No** son sprites listos para usar ni fondos de una sola pieza que deban importarse directamente como nivel jugable.

- 01_moodboard_direccion_visual.png: lenguaje visual general, encuadre, paleta y criterios artísticos.
- 02_terreno_organico.png: terreno creíble, troncos, desniveles y estructuras integradas en el entorno; referencia de composición, no de colisión exacta.
- 03_estacion_abandonada.png: arquitectura ferroviaria, puntos focales y calidez puntual.
- 04_protagonista_12_anos.png: exploración del diseño del hermano mayor; es una referencia, no un sprite sheet técnicamente homologado (frames pueden variar).
- 05_fenomeno_temporal.png: referencia narrativa, anomalía del tiempo y dos hermanos separados.

## Reglas
- Conservar el tono propio «Memoria desvanecida», sin copiar imágenes, personajes o composiciones de juegos comerciales.
- Mantener el paisaje visible y las plataformas claramente distinguibles de la decoración.
- Trabajar sobre `Assets/Scenes/ForestOrganicDemo.unity`; no crear una escena distinta para cada feature.
- Las imágenes aquí son referencias; al integrarlas en Unity, habrá que crear recursos separados por capas, sprites y animaciones adecuados y mantener colisiones alineadas.
- Analizar primero en Cursor Ask. Implementar pequeñas mejoras verificables en Build/Agent, sin cambiar scripts físicos ya validados.
